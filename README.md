# БД «Сотрудники высшего учебного заведения» — web-приложение

Курсовой проект по дисциплине «Базы данных», вариант 12. Олзоев А. А., АСУб-23-2.

Трёхзвенная архитектура: браузер → web-сервер (Python, FastAPI, Jinja2) → сервер БД (PostgreSQL).

## Запуск (Windows)

1. Установить **PostgreSQL 14+** (пароль пользователя `postgres` запомнить) и **Python 3.10+** (галочка «Add to PATH»).
2. Если пароль `postgres` не `postgres`, исправить его в `app/config.py`.
3. Дважды щёлкнуть `run.bat`. При первом запуске он создаст окружение, установит пакеты, создаст БД `vuz_staff`
   с тестовыми данными и откроет http://127.0.0.1:8000.
4. `init_db.bat` пересоздаёт БД с исходными тестовыми данными (все текущие данные удаляются).

Вручную (любая ОС):
```
python -m venv .venv
.venv\Scripts\activate          (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python init_db.py
python -m uvicorn app.main:app --port 8000
```

## Запуск в браузере без установки (GitHub Codespaces)

В проекте есть папка `.devcontainer`: GitHub сам поднимает в облаке Python и PostgreSQL,
создаёт базу с тестовыми данными и запускает приложение.

1. Загрузите содержимое этой папки (вместе с `.devcontainer`) в репозиторий на GitHub.
2. На странице репозитория: зелёная кнопка **Code** → вкладка **Codespaces** → **Create codespace on main**.
3. Через 2–4 минуты приложение откроется в новой вкладке. Если не открылось — вкладка **PORTS** внизу,
   строка с портом 8000, значок глобуса **Open in Browser**.
4. В следующий раз: **Code** → **Codespaces** → выбрать уже созданный codespace (запускается за ~30 с).

| `sql/01_schema.sql` | Таблицы, первичные/внешние ключи, генераторы (IDENTITY), ограничения CHECK/UNIQUE, индексы |
| `sql/02_logic.sql` | Триггеры контроля данных с исключениями, представления, хранимые функции и процедуры |

## Модель данных

Отдел → Факультет → Кафедра → Лаборатория (1:М). Сотрудник закреплён ровно за одним подразделением любого уровня
(CHECK `num_nonnulls(...) = 1`), справочники: должность (с признаком ППС), учёная степень, учёное звание, тип телефона.
Телефоны вынесены в отдельную таблицу (у сотрудника их несколько).

Объекты сервера БД:
- **Триггеры/исключения:** `tr_сотрудник_проверка` (ФИО, год рождения 1940…текущий−18, стаж ≤ возраст−14, стаж НПР ≤ общего),
  `tr_телефон_проверка` (формат номера), `tr_*_удаление` (запрет удаления подразделения с сотрудниками/подчинёнными).
- **Представления:** `v_подразделение` (иерархия с путём), `v_сотрудник` (полные сведения с телефонами).
- **Функции:** `fn_телефонный_справочник`, `fn_сотрудники_по_стажу`, `fn_сведения_нпр` — выходные документы 1–3;
  `fn_в_подразделении`, `fn_статистика`.
- **Процедуры:** `sp_начислить_стаж` (меню «Сервис»), `sp_перевести_сотрудника` (перевод из карточки).

## Формы

- форма-таблица: списки сотрудников, подразделений и справочников (поиск, сортировка по столбцам);
- формы редактирования: личная карточка сотрудника (с телефонами), подразделение, запись справочника;
- «родительская — дочерняя»: карточка подразделения (подчинённые подразделения и сотрудники), схема подразделений;
- выходные документы (меню «Отчёты», печать через кнопку «Печать» или Ctrl+P).
